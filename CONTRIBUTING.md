# Вклад в проект

Спасибо за интерес. Проект ведёт один человек, поэтому перед большой работой откройте issue и обсудите идею.

## Лицензия вклада

Код распространяется по [PolyForm Noncommercial 1.0.0](LICENSE): использовать, изменять и делиться можно для некоммерческих целей с сохранением строки `Required Notice` с именем автора. Отправляя PR, вы соглашаетесь, что ваш вклад распространяется на тех же условиях, а автор проекта может использовать его, в том числе в коммерческих лицензиях проекта.

## Как внести изменение

1. Форкните репозиторий и создайте ветку от `main`.
2. Установите зависимости: `npm ci`.
3. Перед PR запустите `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` (то же делает CI).
4. Изменение поведения для пользователя поднимает версию `0.MINOR.PATCH` в `package.json` и `package-lock.json` и добавляет раздел в [CHANGELOG.md](CHANGELOG.md). Формат раздела: заголовок `## X.Y.Z · ГГГГ-ММ-ДД` и строки `- ...` (сборка разбирает этот файл для окна «Что нового»).
5. Миграции БД описывайте в PR и не применяйте к production без разрешения владельца.
6. Не добавляйте секреты, ключи и персональные данные в код, документы и описания.

## Правила кода

- Бизнес-правила живут в `src/domain`, их используют и бот, и Mini App; арифметика денег и КБЖУ выполняется кодом, не ИИ.
- Отступы Telegram только через `--lifeos-inset-top` и `--lifeos-inset-bottom` (проверяет `tests/safe-area.test.ts`).
- Дизайн: светлый Liquid Glass, бордовый акцент, без эмодзи; перед изменением интерфейса прочитайте [DESIGN.md](DESIGN.md).
- Коммиты, PR и документация пишутся нейтрально.

Безопасность: см. [SECURITY.md](SECURITY.md).
