# Факты из репозитория Stumpy_LifeOS, на которые опирается ролик

Ревизия: `main` @ 2f1a70c (1.0.0-rc.2). Репозиторий не менялся.

## Бот
- Черновик: `src/server/telegram/handlers/drafts.ts` → `formatDraft()`:
  `Проверь, пожалуйста · <дата dateStyle:medium + timeStyle:short, ru-RU>`, `Еда: <label> · <portion>`,
  `КБЖУ: N ккал · Б x · Ж y · У z г`, `КБЖУ оценены примерно.` (если оценка), `Расход: <label> · <сумма>`, `Категория: …`.
- Клавиатура черновика: ряд «Записать», «Исправить»; второй ряд «Отменить» (`draftKeyboard`).
- Длинный чек (>5 денежных позиций, `MAX_SEPARATE_DRAFT_MESSAGES = 5` в `handlers/messages.ts`) — одно сообщение `formatDraftList()`:
  `Проверь, пожалуйста · позиций: N`, `1. <label> · <сумма> · <категория>`, `Итого: …`, пояснение про отдельные операции; кнопки «Записать все» / «Отменить все» (`bulkDraftKeyboard`).
- Подтверждение: `src/server/telegram/confirmation.ts` → `Записал еду: <name> · <portion>` + строка КБЖУ; `Записал расход: <name> · <сумма>`.
- Фото: `handlers/messages.ts:152` — статус «Смотрю фото…», затем тот же статус редактируется в «Сверяю детали перед записью…» (стр. 172) и «Готовлю отдельные черновики для подтверждения…» (стр. 182), после чего удаляется. Для текста первый статус — «Разбираю сообщение…».
  **Расхождение с ТЗ:** в ТЗ сказано, что многостадийного прогресса нет; в коде три реальных статуса. В ролике показаны именно эти три.
- Примеры сообщений: `src/domain/welcome.ts` («съел гречку с курицей», «кофе 45»).
- Суммы в чате: `formatMoneyPlain()` в `src/domain/currencies.ts` → `85,00 руб. ПМР` для `PRB`. В Mini App — `formatMoney()` / `currencyUnit("PRB")` → `р. ПМР`; имя валюты `Рубль ПМР`.
- Категории из кода ИИ-разбора: «Продукты», «Кафе и рестораны» (`src/server/ai/clarification.ts`, `analyze.ts`).

- «Сегодня»: одна `GlassSurface`, секции «Питание» (ссылка «Дневник»), «Финансы» («Операции»), «Зал» («План»); `Stat` «Основной счёт», «Потрачено сегодня»; кнопки «Записать еду», «Записать операцию»; «Начать».
- «Питание»: навигация ‹ «Дневник» ›, кнопки «Добавить запись», «Цель КБЖУ»; «По времени» / «Записи» + счётчик; строка записи `порция · ккал · Б / Ж / У г · оценка`.
- Отчёт «Динамика КБЖУ», переключатели «Калории», «Белки», «Жиры», «Углеводы» (`src/components/reports/module-reports.tsx`).
- «Финансы»: вкладки «Обзор», «Операции», «Планы», «Долги»; «Текущий баланс», «<счёт> · <валюта>», «Потрачено сегодня», «За месяц», «Добавить операцию»; «Счета»/«Мои счета»/«Управлять»; «Движение денег»/«Операции»/«Добавить»; расход «−», доход «+». Отчёт «По категориям».
- Планы: `finance-plans-view.tsx` — «Будущие покупки», «Планы покупок», «Добавить в план», «Всего запланировано».
- Долги: `finance-debts-view.tsx` — «Долги», «Я должен» («Мои долги другим людям»), «Мне должны».
- Зал: «К плану», «Тренировка», «Продолжить», `· Было …`, `· Можно увеличить вес`; экран упражнения «К тренировке», «В прошлый раз: …», «Подход / Результат / Статус», «Отметить»/«Готово», «Таймер отдыха», «Между подходами · 01:30», «Старт / Стоп / Сбросить».
- Нижняя панель `ActionSheet`: «Быстрое действие», «Питание», «Записи можно добавлять сообщением или фотографией в чате с ботом.», пункты «Записать еду / Текст или фото · КБЖУ», «Внести массу тела», «Настроить цель КБЖУ».
- Настройки: `src/components/settings/settings-menu.tsx` — «Персонализация», «ИИ-провайдеры», «Данные и приватность» с описаниями; видимого заголовка «Настройки» нет (только aria-label).
