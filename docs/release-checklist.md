# Чек-лист релиз-кандидата

Проходится вручную на реальном устройстве перед тегом `1.0.0-rc.1` и после каждого заметного исправления в RC. Автоматические проверки (lint, typecheck, тесты, build) идут в CI и сюда не входят. Результат прогона записывайте в [status.md](status.md): дата, устройство, что не прошло.

## Перед выпуском

- [ ] CI на `main` зелёный, защита ветки включена.
- [ ] `/api/health` на production отдаёт версию из `package.json`; Vercel Production собран из merge commit.
- [ ] Применены все миграции из `drizzle/`: `GET /api/ready` с `CRON_SECRET` отвечает `200` (сверка журнала `drizzle.__drizzle_migrations` с `drizzle/meta/_journal.json`). Правило: SQL новой миграции применяется в production до merge PR ([развёртывание](deployment.md#4-миграции)).
- [x] `CRON_SECRET` и `TELEGRAM_WEBHOOK_SECRET` не слабее 32 символов (проверено 2026-11-15, 64 hex).
- [ ] Учения восстановления Neon (ветка и PITR) пройдены ([operations.md](operations.md), «Проверка восстановления»); восстановление на уровне приложения уже проверено 2026-11-15.
- [x] Юридическая проверка [privacy-policy.md](privacy-policy.md) и [terms.md](terms.md) не проводилась: для 1.0 это осознанное решение владельца (2026-11-16). Открытые вопросы перечислены в конце политики.

## Вход и согласие

- [ ] Новый профиль: экран согласия с тремя галочками (18+, политика и условия, данные о здоровье); без согласия API отвечает 403, экспорт и удаление работают (в боте `/export` и `/delete`).
- [ ] Gemini и бесплатные модели OpenRouter: предупреждение и галочка, без галочки ключ не сохраняется.
- [ ] Бот: `/start` у нового пользователя просит согласие.
- [ ] Настройки → «Данные и приватность»: экспорт приходит файлом в Telegram; удаление данных с подтверждением стирает профиль.

## Mini App без ИИ (всё вводится руками)

- [ ] Профиль и цель, вес (запись, правка, удаление).
- [ ] Питание: еда с КБЖУ, правка, удаление, смена дня.
- [ ] Финансы: первый счёт задаёт основную валюту, операция в другой валюте с курсом, перевод, план покупки, долг и возврат.
- [ ] Зал: день и упражнения, тренировка, подходы, таймер отдыха, завершение, журнал.

## Бот и ИИ (BYOK)

По каждому провайдеру (Gemini, Groq, OpenRouter, свой endpoint):

- [ ] Подключение ключа, проверка, выбор бесплатной модели.
- [ ] Сообщение с едой и расходом даёт два отдельных черновика с «Записать», «Исправить», «Отменить».
- [ ] Исчерпанная квота переключает на следующий аккаунт (fallback), а при нехватке всех — понятное сообщение.

## Telegram WebView

На iOS и Android, в полноэкранном режиме:

- [ ] Safe area сверху и снизу на каждом экране (шапка, док, нижние панели, модальные окна).
- [ ] Клавиатура не закрывает поле ввода и кнопку «Записать».
- [ ] Кнопка «Назад» Telegram ведёт по экранам, а не закрывает приложение.
- [ ] Светлая и тёмная тема Telegram, увеличенный системный шрифт.

- [ ] Приходят вечерняя и недельная сводки и напоминание по просроченному долгу.
- [ ] Зависший update повторяется (см. [operations.md](operations.md)).
