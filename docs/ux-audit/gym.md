# UX audit: Зал (uid 777003, LAT=300, 390x844)

Not tested: finish of the rest timer at 00:00 (90s wait not run), duplicate/huge-number server errors beyond native validation, "Заменить" submit, adding a custom exercise end-to-end, add-exercise sets/reps/rest validation. Screenshots viewed: g2, g3, g4, g6, g7-bottom, g9, g10, g11, g20 (in ux-gym/).

## Worked well
- Gym root is clear: "Сегодня" card with one primary button, plan, progress and journal in order.
- Empty states have text: "Истории рабочих весов пока нет...", "Завершённых тренировок пока нет.", "В этой тренировке пока нет упражнений."
- Set sheet has correct units (кг, секунд, м), decimal 82,5 shown in Russian format, correction of a logged set works (tap "Готово" reopens prefilled).
- Double tap on "Добавить день" and "Сохранить результат" sends one request.
- Rest timer auto-starts after a saved set, keeps running when leaving and returning to the exercise.
- Replacing an exercise explains "Количество подходов... останутся прежними. История... сохранится."
- Tap targets are >= 44px everywhere measured; reorder buttons have descriptive aria-labels.
