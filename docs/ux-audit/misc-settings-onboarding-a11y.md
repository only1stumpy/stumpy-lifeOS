# UX audit: onboarding, settings, AI wizard, quick text box, a11y, navigation (LifeOS 0.15.1)

Method: headless Chrome 390x844 touch, LAT=300, users 777004 (onboarded as Finance-only, skipped profile, later toggled modules in Settings) and 777005 (onboarded Nutrition-only with profile, then owner_settings reset via the harness's own reset.mjs and re-onboarded as Gym-only). 777001 read-only for a11y/responsive. Screenshots in ux-misc/. Looked at ~12 images; everything else is DOM/computed-style measurement, stated as such.

## Onboarding map (verified)

- Steps: modules (3 cards, all checked) > usage (3 radios, "Каждый день" preselected) > profile (only if Nutrition on) > currency (only if Finance on) > opening balance (Finance) > AI key.
- Counter: "Шаг 1 из 6" with all modules; recalculates live: Finance-only "из 5", Nutrition-only "из 4", Gym-only "из 3" (modules, usage, AI). Good, but the number jumps when the user toggles cards on step 1.
- Back: works, keeps checks; no Back on step 1 and none on the AI step.
- Landing: dock shows only enabled modules (Finance-only: Сегодня/Финансы/Настройки; Nutrition-only: Сегодня/Питание/Настройки; Gym-only: Сегодня/Зал/Настройки). All three with a "Что нового" dialog on top (M3).
- Skipped profile (Finance-only user): Nutrition enabled later shows "0 ккал · цель не задана / Добавьте параметры..." (no crash).

## Worked well

- Per-field inline errors in the profile ("Выберите пол", "Укажите возраст", "От 16 до 90") with red border and a live norm preview ("Норма на день: 2 200 ккал · Б 112 ...") before saving.
- Step counter adapts to selected modules; the dock and every screen follow the module choice, including the empty states of Gym ("План пока не создан. Соберите тренировочные дни и упражнения.").
- "Сохраняю…" is shown while saving; custom currency "prb" is normalized to "р. ПМР".
- Settings refuses to disable the last module with a clear message ("Оставьте хотя бы один раздел.") and dependent features grey out when their parent is off.
- AI-not-configured reply is fast, specific and keeps the manual form usable ("Можно внести данные вручную."), so the app works without AI as designed.
- Visible focus ring (3px burgundy at 65%) on all interactive elements; Tab order follows reading order and ends in the dock.
- No horizontal overflow at 320/360/390/768 on 10 screens; nothing hidden behind the dock at the end of scroll; all measured buttons >=44px except the calendar cells; sheet close buttons are 48x48.
- Sheets close with Escape consistently; sheet motion respects reduced motion.
