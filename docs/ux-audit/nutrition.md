# UX audit: Today + Питание (uid 777002, 390x844, LAT=300)

Scope covered: Today blocks and links, Питание (diary, quick menu, add form, AI parse without a key, edit, delete, template, weight, goal/profile, calendar, charts). Screenshots in ux-nutrition/. Test data changed for 777002: one "Тест йогурт" entry (500 ккал) left, Борщ edited to 450 ккал, goal re-saved (macros 125/486 became 124/487), weight series ends 77,4 (several same-day replacements), a workout was started via Today "Начать".

## Worked well

- Today is a clear single surface: nutrition (kcal, Б/Ж/У bars, remaining) and finance, every link/button is a real target (>= 44 px) and leads where the label says ("Дневник", "Операции", "План" are tab switches).
- Tab switching and the calendar/chart interactions are instant after the first snapshot (0 API).
- Delete asks for confirmation with the item name; empty-day text is clear; weigh-in replaces the same date instead of duplicating.
- "Разобрать" without an AI key answers within one round trip and says that manual entry is possible; the manual form is complete and usable without AI.
- Week/month chart footnote "Разрыв линии означает, что в этот день не было записей. Это не нулевое потребление." is exactly the right explanation; chart has accessible labels (aria "График массы тела: от ... до ...").
- Russian number formats on screen (1 320, 77,4), numeric fields use correct decimal comma in browser messages, goal sheet uses `inputmode` decimal/numeric for profile fields.

## Not verified

- Decimal comma typing in number fields (only validation messages checked), real keyboard behavior, over-target colouring, recalculation proposal in the bot, Today for brand-new users with no data, and template reuse in the bot.
