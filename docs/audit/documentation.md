## Сводка и оценка

**Оценка: 5/10.** Содержание богатое и честное по границам проверки (нигде не выдаёт непроверенное за проверенное), CHANGELOG и DESIGN в целом точны. Но «статусные» документы отстали от кода на 2–3 недели: четыре места со статусом «на 29 октября» (README, product, architecture, implementation-plan), три разных числа миграций в production (`0000`–`0006`, `0000`–`0007`, `0000`–`0011`) при фактических 14 (`0000`–`0013`), устаревшие утверждения о валютах и ИИ-ключах окружения. Нет развёртывания «с нуля», runbook, лицензии, SECURITY, CONTRIBUTING, ADR. Двойной AGENTS.md/CLAUDE.md, исторические аудиты без пометки, абзацы по 1–3 тыс. символов в одну строку.

Факты, с которыми сверялось:
- `package.json`: версия 0.22.0, Node `>=22`, Next 16.4.3, React 19.3.0, TypeScript 5.9.3, Zod 4.6.7, grammY 1.46.0.
- `drizzle/`: 14 SQL-файлов, `drizzle/meta/_journal.json` — 14 тегов, последний `0013_draft_message_id`.
- `src/db/schema.ts`: 29 таблиц (`pgTable`, строки 25–764).
- Маршруты `src/app`: `/` и `api/{ai-providers,ai-quotas,commands,cron,export,snapshot,telegram}`; ещё два пустых каталога `src/app/finance-plans-preview` и `src/app/api/telegram/setup` (в git не отслеживаются, но лежат в рабочей копии).
- Тесты: 13 файлов, около 115 `test(` (в docs везде «86»).
- Нет: `.github/` (CI-конфигурации), `vercel.json`, `LICENSE`, `SECURITY.md`, `CONTRIBUTING.md`.
- Ссылки: проверены все относительные Markdown-ссылки во всех перечисленных документах — **мёртвых нет**.
