# Проверенные тексты бота LifeOS (для роликов)

Сверено с `~/Projects/Stumpy_LifeOS` @ 1.0.0-rc.2. При сомнении перепроверить файл: код важнее этого списка.

## Черновик (`handlers/drafts.ts`, `formatDraft`)
```
Проверь, пожалуйста · 16 нояб. 2026 г., 13:42     ← Intl ru-RU dateStyle medium + timeStyle short
Еда: <название> · <порция>
КБЖУ: N ккал · Б x · Ж y · У z г
КБЖУ оценены примерно.                              ← только если оценка
Расход: <название> · 425,00 руб.                    ← или «Доход: …»
Категория: <категория>
```
Кнопки: ряд «Записать» | «Исправить», второй ряд «Отменить». Еда и расход из одного сообщения — два отдельных черновика.

## Подтверждение (`confirmation.ts`, `formatConfirmedRecords`) — сообщение черновика редактируется
- `Записал еду: <название> · <порция>` + строка `КБЖУ: …`
- `Записал расход: <название> · <сумма>` / `Записал доход: …`

## Фото (`handlers/messages.ts` ~152–195)
Статус «Смотрю фото…» → редактируется в «Сверяю детали перед записью…» → «Готовлю отдельные черновики для подтверждения…» → удаляется. Для текста первый статус «Разбираю сообщение…».
Больше 5 денежных позиций — одно сообщение `formatDraftList`:
```
Проверь, пожалуйста · позиций: N
1. <название> · <сумма> · <категория>
Итого: <сумма>
Каждая позиция запишется отдельной операцией. Отдельную позицию потом можно поправить или удалить в Mini App → Финансы.
```
Кнопки «Записать все» | «Отменить все». До 5 позиций — отдельные черновики + «Черновиков: N. Можно подтвердить каждый отдельно или все разом.»

## Вес без ИИ, без кнопок (`saveWeightFromChat`)
```
Записал вес 72 кг на сегодня.
Прошлый замер 15.11: 73 кг (-1 кг).
Ошибся — пришли правильный вес, он заменит сегодняшний.
```
Внимание: дробный вес выводится с точкой («72.4»), а разница с запятой («-0,4»). Для ролика брать целые значения.

## План покупки без кнопок (`handlers/messages.ts` ~113)
`Запланировал «<название как написано>» — 9 000,00 руб. Это пока не расход.` Название сохраняется в регистре пользователя.

## Справочный вопрос, только чтение (`reference.ts`)
- `Сегодня записано расходов на 1 925,00 руб.`
- `За этот месяц записано расходов на …`

## Долг (`drafts.ts`, `callbacks.ts`)
Черновик `Долг: ты должен <имя> · <сумма>`; подтверждение `Записал новый долг и финансовую операцию: Ты занял у <имя> · …`. Имя подставляется как распознано, падежи могут не совпасть — для роликов лучше не использовать.

## Примеры сообщений из справки (`domain/welcome.ts`)
«съел гречку с курицей», «кофе 45», «вес 72,4», «я должен Ивану 500», «запиши в планы шампунь за 220р», «получил зарплату 15000», «сколько я потратил за неделю?».
